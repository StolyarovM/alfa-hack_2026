
# Бизнес-процесс
1. Предприниматель входит в демо-кабинет.
2. Просматривает профиль и историю заявок.
3. Заполняет анкету потребности; rule-based сервис предлагает продукты.
4. Выбирает продукт и указывает сумму.
5. Заполняет минимальную форму: ИНН, возраст ИП, выручка, ежемесячные кредитные платежи,
   наличие просрочек и залога.
6. Backend получает недостающие признаки компании из mock-сервиса.
7. Backend вычисляет долговую нагрузку = платежи / выручка * 100.
8. Выполняются тестовые проверки и формируется ровно 13 полей JSON скоринга.
9. Результат и этапы отображаются в трекере.
