
# Безопасность
Использовать только синтетические данные. Пароли хранятся как Argon2-хэши; API защищено JWT,
заявки фильтруются по текущему пользователю. Секреты хранить в `.env`, не коммитить.
Для production обязательны HTTPS, секрет-менеджер, ротация ключей, rate limits, аудит,
политика удаления данных, проверка прав и независимый security review.
