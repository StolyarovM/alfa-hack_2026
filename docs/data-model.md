
# Модель данных
- users: учётная запись, хэш пароля, ИНН и название бизнеса.
- companies: синтетические признаки компании.
- applications: введённые параметры заявки, сумма, продукт, статус и результат.
- verifications: результаты внешних проверок.
- scoring_results: входной JSON, ответ и метка режима/версии модели.
- surveys: ответы анкеты потребности.
- audit_events: журнал событий.
В MVP связи заданы внешними ключами SQLAlchemy. Перед production нужны миграции и политика хранения.
