
# Скоринговая модель
Backend отправляет JSON с ключами `Тип_продукта`, `Возраст_ИП`, `Срок_работы_мес`,
`Выручка_в_месяц`, `Оборот_в_месяц`, `Сотрудники`, `Долговая_нагрузка_процент`,
`Действующие_кредиты`, `Просрочки`, `Отрасль`, `Счет_в_банке_мес`, `LTV_залога`,
`Сумма_кредита`. Ожидаемый ответ: `{"риск": 0.0, "решение": "..."}`.
Уточните у владельца модели URL пути, метод, авторизацию, формат и шкалу риска.
Демо-fallback — только для прототипа, он не заменяет реальную модель.
